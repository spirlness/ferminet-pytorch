# R1–R9 修复记录（2026-09-22）

本记录对应 `review_20260922.md` 的反例；原始报告和 JSON 测量保持不改写。

| 项目 | 修复与回归证据 |
|---|---|
| R1 | Geyer 配对改为 `(rho_0+rho_1), (rho_2+rho_3), ...`，再作初始正序列与单调化；短于 50 个时间步的非常数链明确为 `unresolved`。`test_mcmc_stats.py` 覆盖 IID、正/负 AR(1) 混合可逆链（解析 `g=5.0556`）和短链。 |
| R2 | 1–4 阶 Slater 块采用无除法 Berkowitz 行列式多项式；其一至三阶导数在奇异和重复行分支与独立置换多项式一致，且 `torch.func.jvp`/`vmap`、exact、exact_jvp、Hutchinson 都有回归。大矩阵直接在 `slogdet` 对数尺度组合，避免 float32 原始行列式下溢。 |
| R3 | Hatch 明确列出运行模块并用 `sources` 前缀写入 `ferminet_pytorch/`；sdist 排除测试与审计。隔离 wheel、sdist 及 editable 安装均完成公开导入和小型前向验证。 |
| R4 | `nucleus_group_index` 已入检查点；旧 FermiNet 检查点只可由其保存的核电荷重建，索引/电荷冲突明确拒绝。 |
| R5 | 一致性检查增加 `n_up/n_down`；冻结复评在采样前确认模型、体系和 walker 形状，验证后刷新缓存。 |
| R6/R7 | 公共默认改为笛卡尔相对特征；纯距离模式必须显式传 `rotation_invariant=True`。各向异性包络与旋转不变选项组合会抛出 `ValueError`。H2 示例和历史基准显式使用纯距离模式。 |
| R8 | 删除固定 `1e-38` 幅度下限。组合采用脱离计算图的行列式/权重公共尺度与对数尺度；float64 的 `1e-45` 整体权重缩放保持坐标导数和局域能量不变，真节点仍为 `(-inf, 0)`。 |
| R9 | 当前缓存中的 NaN 或 `+inf` 立即抛出 `FloatingPointError`，不写替代值；`-inf` 节点保留。两种提议模式均拒绝 NaN/Inf 提议。 |
