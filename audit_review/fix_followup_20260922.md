# 首次交付复核后的后续修复（2026-09-22）

该记录追加在 `fix_20260922.md` 之后，保留原始审查报告和测量 JSON 不变。

复核发现并修复了以下行为：

- 通用矩阵不再在 4 阶以上回退到奇异不安全的 `slogdet` 反向。行尺度化避免原始行列式下溢/溢出；非奇异分支采用稳定 LU 对数幅值，秩亏分支采用无除法 Berkowitz 多项式，前向节点通过直通形式保持余子式和高阶导数。
- LiH 的 `[3, 1]` 核电荷不再被误认为“未共享”而重建为 `[0, 1]`。检查点迁移现在根据保存的 `tie_nuclear_envelope` 架构语义重建 `[1, 0]`，新检查点和缺少分组索引的旧检查点输出一致。
- 上下自旋块在乘积之后才进行共同尺度化；因此 `[1e200, 1e-200]` 与其倒数的两个分支仍给出 `log(2)`，而不是假节点。NaN 分支保持非有限并由 MCMC 缓存守卫报告。
- 新增极端尺度、重复/近奇异矩阵、LiH 迁移、NaN 传播和 CUDA 路径回归。CUDA 回归在无 CUDA 主机上自动跳过，不能替代真实 GPU 验证。

本次新增回归位于 `test_r1_r9_regressions.py`。验证命令：

```text
uv run python -m unittest test_r1_r9_regressions.py -q
```
