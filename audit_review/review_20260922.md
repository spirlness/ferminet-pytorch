## R1 · P1 · Geyer 自相关配对错位，长链仍会低估误差

位置：`mcmc_stats.py:56-74`，尤其从 `lag=1` 开始的配对。

实现将 `(rho1+rho2), (rho3+rho4), ...` 视作 Geyer 初始正/单调序列。Geyer 对可逆链的正性与单调性保证针对 `(rho0+rho1), (rho2+rho3), ...`；对应 `g=-1+2*sum(pairs)`。当前代码的错位配对在含负特征模态的链上不成立，不只是有限链长偏差。

独立复现使用两个平稳、独立、可逆 Gaussian AR(1) 过程的加权和：

```
rho(t) = 0.05 * 0.98**t + 0.95 * (-0.8)**t
g_exact = 0.05 * (1+0.98)/(1-0.98)
        + 0.95 * (1-0.8)/(1+0.8)
        = 5.0555555556
```

32768 时间步 × 32 walkers，初态取平稳分布：

| 量 | 结果 |
|---|---:|
| 当前估计 `g` | 1.0 |
| `autocorrelation_status` | `ok` |
| split R-hat | 1.000099 |
| 同一数据、正确配对后的 `g` | 4.970535 |
| 当前 SEM 低估倍数 | 约 2.25 |

第一错误配对的解析值为 `rho1+rho2=-0.05498`，直接导致截断。这是已平衡长链上的反例，增加当前默认 32 步的链长不能修复配对逻辑。并未声称本项目 H2 的具体 MH 链已出现该协方差谱；公开统计函数接受通用链数据，当前算法声明和行为不相符。

建议：修正配对及 `g` 公式，以正相关 AR(1)、负相关 AR(1)、正负模态混合可逆链共同回归；明确是否保留 `g>=1` 的保守下限。

依据：[Stan 官方公式](https://mc-stan.org/docs/reference-manual/analysis.html)、[Geyer 本人的初始序列说明](https://www.stat.umn.edu/geyer/mcmc/library/mcmc/html/initseq.html)。证据 JSON：`geyer_pairs`。

## R2 · P1 · 单个行列式奇异会使非零总波函数的梯度失效

位置：`model.py:303-311` 的 `torch.linalg.slogdet`，以及 `333-343` 的事后掩码。

H2 的两个行列式分支中，将第一个 up 轨道的权重与偏置设为零，第二分支保留。该参数状态合法，且在所测构型总波函数非零、光滑。

- 正向 `log|Psi|=-2.6331406674`，`sign=+1`。
- 当前坐标梯度出现非有限值。
- 局域能量抛出 `torch.linalg.solve ... input matrix is singular`。
- 独立直接计算 `sum_k w_k * up_k * down_k`，得到相同的对数幅值且坐标梯度全部有限。

这里零的是一个分支，**不是总波函数节点**，不能把失败归为物理上本应发散。对 `slogdet` 输出进行掩码不会阻止其反向路径处理奇异矩阵；零权重恢复测试也没有覆盖零行列式。

建议：至少对 1×1 自旋块保留普通乘法，避免先取其对数；更大矩阵的多行列式组合需要在单分支奇异时仍有定义的求导策略，不能简单删去该分支导数。增加“单分支为零、总和非零”的坐标、参数和二阶导数测试。

[官方 FermiNet 的实现](https://github.com/google-deepmind/ferminet/blob/main/ferminet/network_blocks.py) 对 1×1 块也专门绕开对数域。该参考只能支持此局部修复思路，不能证明任意尺寸奇异矩阵问题已经解决。证据：`singular_branch`。

## R4 · P2 · 检查点遗漏核分组映射，加载成功却改变波函数

位置：`envelope.py:86-103`，`nucleus_group_index` 注册为 `persistent=False`；`model.py:130-131` 的电荷/坐标却正常进入检查点。

LiH 模型源电荷顺序 `[3,1]` 对应分组 `[1,0]`。用相同架构、初始电荷 `[1,3]` 构造接收模型，再以 `strict=True` 加载源 `state_dict`。电荷和坐标被覆盖为源模型内容，但包络分组仍停留在接收模型构造时的 `[0,1]`。

- 加载返回 `<All keys matched successfully>`。
- 两个模型 `state_dict` 中的所有张量逐项完全相同。
- `check_system_consistency` 通过。
- 设置不同电荷组具有不同衰减率后，4 个固定构型上 `max|delta log(Psi)|=0.648163`、`max|delta E_L|=0.803714 Ha`。

该反例需要接收模型构造时的电荷分组不同；完全相同构造参数的普通 round trip 不触发。问题在于当前加载流程既不恢复也不校验这个影响物理输出的状态。

## R5 · P2 · 一致性检查漏掉自旋分区，可求解错误的电子态

位置：`model.py:529-545`，调用点 `train_vmc.py:253-255`。

当前只检查几何和电荷。将 H2 `MolecularSystem(n_up=1,n_down=1)` 与同几何、电荷、总电子数但 `FermiNet(n_up=2,n_down=0)` 组合，训练和复评均成功；返回系统元数据仍为 `(1,1)`，参考能量仍选 `-1.17447 Ha`。

两个同自旋电子的空间波函数必须反对称；这与使用 H2 单重态基准所需的电子态不同。总电子数相等不能证明交换对称性或自旋设定一致。微型复现的 `-0.80996 Ha` 只是路径接受错误组合的证据，不作收敛能量解释。

建议：构建采样器前同时核对 `n_up`、`n_down`；独立复评入口也应校验模型、系统和采样器对应关系。证据：`spin_mismatch`。

## R6 · P2 · 默认纯距离特征排除部分合法原子基态

位置：`model.py:56`、`features.py:145-151,174-175`。

在单核原子、默认各向同性包络下，所有输入是 `|r_i|`、`|r_i-r_j|` 和核电荷。因此对任意参数都强制：

```
Psi(Q r) = Psi(r)     (所有正交变换 Q)
Psi(-r)  = Psi(r)     (偶宇称)
```

这也把原子轨道总角动量限制为标量表示。Hamiltonian 的旋转不变性并不意味着每个物理态都应是旋转不变的标量，更不意味着只需偶宇称。

硼原子 `(Z=5,n_up=3,n_down=2)` 的实际基态项为 `2P°`，是奇宇称；参见 [NIST 硼能级表](https://physics.nist.gov/PhysRefData/Handbook/Tables/borontable5.htm)。代码接受该体系却不提示默认 ansatz 排除了目标态。实测 6 个随机非零构型，空间反演后的 log 幅值差严格为零，符号全部不变；奇宇称应翻号。不能靠增加训练步数或行列式数突破这个恒等约束。

这是**从结构与已知态对称性推导出的表达能力问题**，本次没有训练硼原子来测其能量误差，也不把它外推为 H2/LiH 默认示例错误。

建议：保留可表示所需角动量/宇称的特征或等变结构；若维持当前默认配置，明确限制支持的态，并在不兼容配置上拒绝或告警。证据：`atomic_parity`。

## R7 · P2 · 各向异性包络与“严格旋转不变”开关互相矛盾

位置：`model.py:81-88,182`，`envelope.py:179-195`。

`rotation_invariant=True` 可以与 `anisotropic_envelope=True` 同时启用。包络使用实验室坐标轴上的三个独立 sigma，旋转坐标时它们不会作为张量一起旋转。

单核原子，设置各向异性 raw 衰减率 `(0,2,4)`；将同一电子从 `(1,0,0)` 旋转到 `(0,1,0)`：`log|Psi|` 改变 `1.433781`，尽管模型仍声明 `rotation_invariant=True`。初始化时三个方向相同，测试只测初态就无法发现训练后出现的违约。

建议：拒绝这组互相矛盾的选项，或在分子标架中定义可正确变换的度规。回归应显式改变三个轴的参数后再旋转。证据：`anisotropic_rotation`。

## R8 · P2 · 对行列式和的固定截断破坏波函数整体缩放不变性

位置：`model.py:350-353`，`torch.abs(summed).clamp(min=1e-38)`。

对所有行列式权重乘同一个非零常数 c，应只令 `log|Psi|` 增加 `log|c|`，不得改变局域能量。本次在 float64 中取 `c=1e-45`，该值仍可正常表示：

- 对数平移最大误差 `16.53928`。
- 局域能量最大变化 `0.235050 Ha`。

截断生效后，`summed` 的坐标导数被压成零，但 `max_log_det` 的导数仍存在；因此返回的已经不是原先波函数的对数。此问题要求权重整体极小或有特殊严重抵消，不代表默认初始化立即触发。

建议：在区分真零节点后使用保持数学恒等式的缩放方案，考虑 dtype，避免用固定幅度 floor 修改非零波函数。增加不同 c 下的 log 平移、坐标导数和 `E_L` 不变测试。证据：`normalization_scale`。

## R9 · P2 · 当前缓存为正无穷时，MCMC walker 永久冻结

位置：`mcmc.py:166-170`，以及两种移动模式中的 `log_ratio`。

当前值清洗使用 `torch.nan_to_num(..., nan=-1e20, neginf=-1e20)`，没有指定 `posinf`，于是 `+inf` 被变为 dtype 最大有限值。之后任何普通有限提议都得到极负的 log ratio、接受率为零。

构造只在初始原点返回 `+inf`、其它位置返回有限 Gaussian 对数幅值的模型，4 个 walkers 连续 20 步均不移动，缓存为 `1.7976931348623157e308`，不报错。问题同样可能在参数更新后刷新缓存时触发。

非有限模型输出本来就是故障，采样器应显式报错或执行有记录的重新初始化，而不是将它伪装成极高概率、不可离开的状态。清洗提议值的现有保护没有覆盖当前值。证据：`positive_infinite_cache`。

## 已知限制与不应混淆的结论

1. **链间未混合时的 SEM 仍不可直接引用。** 当前按各链自身均值去中心化，再汇总链内自相关，未把链间均值差纳入 ESS。64 条不同偏置的长链得到 `R-hat=990.29`，但 `autocorrelation_status=ok`、ESS=262144、SEM=0.01929；按独立链均值估计约 1.24410。README 已要求检查 R-hat，因此本报告将其列为需要遵守的统计边界，不计为本轮第十个新问题。下游仅引用 `energy_sem` 或 `status=ok` 仍不安全；可增加统一可靠性状态。
2. **未强制 cusp 不等于势能公式错。** clamp 半径外库仑势通过独立验证；完整 ansatz 没有强制电子-核或电子-电子 Kato 条件，学习到的包络衰减率也不是整个波函数 cusp 的充分条件。有限样本训练不能保证消除近核/近节点重尾。
3. **固定几何 ansatz 的核序不变性、转动不变性与变分合法性应分开。** 未强制某种对称性不自动使 Rayleigh 商非法；而强制错误的态对称性会排除目标态（R6）。同自旋反对称性是必要条件，现有测试覆盖它；固定 `n_up,n_down` 只指定磁量子数分区，一般不自动保证任意多电子波函数都是纯 `S^2` 本征态。
4. **Hutchinson 是计算成本与额外方差的权衡。** 条件无偏的随机迹估计可通过足够抽样得到能量估计，但固定构型下相对 exact 会增加随机方差；“只用于训练、禁止报告”是本项目的保守接口策略，不是普适物理定理。“训练期方差缩减”的表述容易误导。
5. **当前编译测试只证明构造 wrapper 成功。** `test_compile_model_disables_internal_compile` 没有实际执行编译后的前向或二阶导，不能据其通过推断 CUDA 高阶导与性能路径可靠。本机没有 CUDA，未对这一点制造实测结论。

## 建议修复与验证顺序

先修 R1/R2，避免用错误误差条或无效导数做物理判断；同步修 R3 以恢复安装交付。随后处理 R4/R5 的状态与体系一致性、R6/R7 的物理态适用范围，再处理 R8/R9 的数值极端情形。每个行为修复应加入对应反例回归。

这些修复后再做多种子 H2/LiH 长训练、冻结参数/步长后的独立长链评估。报告需同时给出 Hamiltonian/几何、均值、SEM、ESS、R-hat、链长与实际求解器；化学精度应由重复实验和误差预算支持，不能由单次局域能量或绿色单元测试替代。
