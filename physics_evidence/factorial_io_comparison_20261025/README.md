# 冻结观察 I/O 与统计回传优化的本地对照

基线为 ae0bc0dc542b932004b7aa75a0766c10af3610c3。环境为 Windows、RTX 3060 Laptop、PyTorch 2.14.0 / CUDA 13.0，显式单 CPU 线程、eager、TF32 关闭。

四组各比较两个临时 10 步更新路径，均丢弃：参数、训练历史、walkers、CPU/CUDA RNG 逐值一致。训练计时没有完整 ABBA 控制，不能据此宣称稳定加速。

冻结模型评估采用 old/new/new/old 的 ABBA 顺序，固定模型、种子、512 walkers、16 条记录、100 步预热、每条 20 步、能量批次 128；E/T/V、坐标、符号及时间/walker 标识逐值一致。额外 no-grad 前向与复用坐标前向的 log 振幅存在最大约 1.78e-15 的舍入差异；首次要求全部字段逐位一致的检查因此失败，原始失败日志保留。之后明确分别检查物理轨迹逐值一致及 log 振幅的 2e-12 绝对容差，不删除样本。

局部 ABBA 总时长比为 1.08219。它是开发机短测结果，不是 T4 加速比或正式实验精度结果。后续必须以固定新源码完成真实双 T4 短测和同一预算门槛。

完整 .pt 对照轨迹位于忽略的 campaign_runs/factorial_io_baseline_20261025/；本目录保留复现脚本、原始日志和基线源码。脚本使用当前库与固定父文件，不是恢复旧运行库的兼容入口。
